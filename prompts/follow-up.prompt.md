# Follow-Up de Proposta Comercial

Generate a professional follow-up message in Portuguese (pt-BR) for a business proposal.

## Context
- **Provider**: Vinícius Ribeiro — WhatsApp (18) 99631-1933
- Review the conversation for client name, service type, and proposal date

## Rules
- Tone: profissional mas próximo, use "você"
- Keep it short (3-5 parágrafos max for email, 2-3 messages for WhatsApp)
- Never be pushy or aggressive
- Always add value (tip, insight, case study) — don't just ask "e aí?"
- Include a soft CTA (pergunta, sugestão de call)
- Reference something specific from the proposal

## Output Format
Generate TWO versions:

### 1. WhatsApp (curto)
- 2-3 mensagens separadas (não um textão)
- Use emoji com moderação (1-2 por mensagem)
- Inclua link para agendar conversa se possível

### 2. E-mail (formal)
- Subject line atrativo (não "Follow-up da proposta")
- Saudação → contexto → valor → CTA → assinatura
- Max 150 palavras no corpo

## Timing Guidelines
- **3 dias**: Primeiro follow-up — "queria saber se teve alguma dúvida"
- **7 dias**: Segundo — agregar valor, enviar insight ou case
- **14 dias**: Terceiro — oferecer alternativa (outro pacote, escopo reduzido)
- **21+ dias**: Final — "portas abertas", sem pressão
