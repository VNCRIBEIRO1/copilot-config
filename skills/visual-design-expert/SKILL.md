## Core Knowledge Areas

### 1. Adobe Photoshop Mastery

#### Fundamental Tools & Techniques
- **Layers & Layer Management**: Use layers for non-destructive editing. Organize with groups, colors, and naming conventions. Use Smart Objects for scalable, editable embedded content.
- **Selection Tools**: Master Quick Selection, Magic Wand, Pen Tool (Bézier curves), Lasso, Select Subject (AI-powered), and Select & Mask for hair/fur refinement.
- **Masks**: Layer masks for non-destructive hiding/revealing. Clipping masks for confining effects. Vector masks for sharp-edged shapes.
- **Blend Modes**: Multiply (darken), Screen (lighten), Overlay (contrast), Soft Light (subtle contrast), Color (recolor). Use blend-if sliders for advanced compositing.
- **Adjustment Layers**: Curves (precise tonal control), Levels (black/white/mid points), Hue/Saturation, Color Balance, Vibrance, Selective Color. Always non-destructive.

#### Advanced Techniques
- **Compositing**: Combine multiple images seamlessly. Match lighting direction, color temperature, perspective, and resolution. Use luminosity masks for natural blending.
- **Retouching**: Frequency separation for skin (texture on high-frequency layer, tone on low-frequency). Dodge & Burn for sculpting light/shadow. Healing Brush and Clone Stamp for blemish removal.
- **Color Grading**: Use Camera Raw Filter or Curves for cinematic looks. Split toning: warm highlights + cool shadows. LUT (Look-Up Table) application for consistent color themes.
- **Smart Filters**: Apply filters non-destructively to Smart Objects. Stack filters and adjust individually. Blur Gallery (Tilt-Shift, Field Blur, Iris Blur) for depth effects.
- **Actions & Automation**: Record repeatable tasks as Actions. Batch process entire folders. Create droplets for drag-and-drop automation.
- **Content-Aware**: Fill, Move, Scale, and Patch tools for intelligent removal/replacement of elements.
- **Generative Fill/Expand** (2024+): Use AI-powered generation for extending images, adding/removing objects with text prompts.

#### File Management
- **Color Modes**: RGB for screen, CMYK for print. Work in 16-bit for maximum quality, convert to 8-bit for delivery.
- **Resolution**: 72 PPI for web/screen, 300 PPI for print. Always start with the highest resolution source.
- **Export Formats**: PSD (working file), TIFF (lossless print), JPEG (web photos, 80-90% quality), PNG (transparency), WebP (modern web), SVG (vectors).
- **Color Profiles**: sRGB for web, Adobe RGB for photography, CMYK profiles for print (consult printer).

### 2. Web Design Excellence

#### Design Principles
- **Visual Hierarchy**: Guide the eye with size, color, contrast, and whitespace. Most important elements should be most prominent.
- **Grid Systems**: Use 12-column grids for flexible layouts. CSS Grid and Flexbox for implementation. Consistent gutters and margins.
- **Whitespace (Negative Space)**: Essential for readability and elegance. Don't fear empty space — it creates focus and breathing room.
- **Consistency**: Maintain uniform spacing, typography, colors, and component styles across all pages.
- **Accessibility (WCAG)**: Minimum 4.5:1 contrast ratio for text. Descriptive alt text. Focus indicators. Semantic HTML. Screen reader compatibility.

#### Color Theory for Web
- **Color Harmonies**: Complementary (high contrast), Analogous (harmonious), Triadic (vibrant), Split-Complementary (balanced contrast).
- **60-30-10 Rule**: 60% dominant color (background), 30% secondary (sections/cards), 10% accent (CTAs, highlights).
- **Psychological Associations**: Blue (trust/corporate), Green (nature/health), Red (urgency/passion), Gold (luxury/premium), Black (sophistication), White (clarity/clean).
- **Dark Mode**: Design for both light and dark. Use semantic color tokens. Avoid pure white text on pure black.

#### Typography for Web
- **Font Pairing**: One serif + one sans-serif. Or two weights of the same family. Maximum 2-3 fonts per project.
- **Type Scale**: Use a modular scale (e.g., 1.250 Major Third). Base: 16px, then 20px, 25px, 31px, 39px.
- **Line Height**: 1.4-1.6 for body text, 1.1-1.3 for headings. Optimal line length: 45-75 characters.
- **Web Fonts**: Google Fonts (free), Adobe Fonts (Creative Cloud), variable fonts for performance. Always set `font-display: swap`.

#### Responsive Design
- **Mobile-First Approach**: Design for smallest screens first, then enhance for larger.
- **Breakpoints**: Mobile (< 640px), Tablet (640-1024px), Desktop (1024-1280px), Wide (1280px+). Use content-driven breakpoints, not device-specific.
- **Fluid Typography**: Use `clamp()` for responsive font sizes: `font-size: clamp(1rem, 2.5vw, 2rem)`.
- **Responsive Images**: Use `srcset` and `sizes` attributes. WebP format with JPEG fallback. Lazy loading with `loading="lazy"`.

#### UI/UX Patterns
- **Navigation**: Sticky header for desktop, hamburger menu for mobile. Breadcrumbs for deep sites. Max 7±2 items in primary nav.
- **Cards**: Consistent padding, subtle shadows, rounded corners. Hover state with elevation change.
- **CTAs (Call to Action)**: High contrast, action verbs ("Get Started" not "Submit"), strategic placement above the fold.
- **Forms**: Single column, clear labels, inline validation, progress indicators for multi-step.
- **Loading States**: Skeleton screens over spinners. Progressive loading for images. Optimistic UI updates.

### 4. Image Editing Fundamentals

#### Exposure & Tone
- **Histogram Reading**: Left = shadows, Center = midtones, Right = highlights. An "ideal" histogram covers the full range without clipping.
- **Exposure Correction**: Adjust highlights, shadows, whites, blacks independently. Recover blown highlights before lifting shadows.
- **Contrast**: Use Curves (S-curve for contrast boost) rather than contrast slider for more control. Clarity/texture for midtone detail.

#### Color Correction & Grading
- **White Balance**: Correct color casts first. Use eyedropper on a neutral gray area or set Kelvin manually.
- **HSL Adjustments**: Target specific colors (Hue shift, Saturation boost/reduce, Luminance lighten/darken) without affecting others.
- **Split Toning**: Add color to highlights and shadows separately for mood (warm highlights + cool shadows = cinematic).
- **Color Matching**: When compositing, use Curves with eyedropper to sample and match shadow/midtone/highlight colors between images.

#### Sharpening & Detail
- **Capture Sharpening**: Apply subtle sharpening (Amount: 40-60, Radius: 0.8-1.2) to compensate for sensor softness.
- **Creative Sharpening**: Use High Pass filter (Overlay blend mode) for targeted detail enhancement.
- **Output Sharpening**: Apply final sharpening based on output (more for print, less for web). Unsharp Mask: Amount 50-100, Radius 0.5-1.0.
- **Noise Reduction**: Balance detail preservation with noise removal. Luminance noise reduction first, then color noise.

#### Cropping & Composition
- **Rule of Thirds**: Place key elements along the intersections of a 3×3 grid.
- **Golden Ratio** (1:1.618): Creates naturally pleasing proportions. Use the golden spiral for eye flow.
- **Leading Lines**: Use natural lines (roads, rivers, architecture) to guide the eye to the subject.
- **Aspect Ratios**: 1:1 (Instagram), 4:5 (Instagram portrait), 16:9 (YouTube/widescreen), 3:2 (photography standard), 2:3 (Pinterest).

### 5. Frames & Borders (Molduras)

#### CSS Frames for Web
```css
/* Simple elegant border */
.frame-elegant {
  border: 3px solid #C9A96E;
  padding: 12px;
  box-shadow: 0 4px 20px rgba(0, 0, 0, 0.15);
}

/* Double border effect */
.frame-double {
  border: 2px solid #333;
  outline: 4px solid #C9A96E;
  outline-offset: 4px;
}

/* Decorative frame with pseudo-elements */
.frame-decorative {
  position: relative;
  padding: 20px;
  border: 1px solid #ddd;
}
.frame-decorative::before,
.frame-decorative::after {
  content: '';
  position: absolute;
  width: 30px;
  height: 30px;
  border-color: #C9A96E;
  border-style: solid;
}
.frame-decorative::before {
  top: -5px; left: -5px;
  border-width: 3px 0 0 3px;
}
.frame-decorative::after {
  bottom: -5px; right: -5px;
  border-width: 0 3px 3px 0;
}

/* Polaroid-style frame */
.frame-polaroid {
  background: white;
  padding: 15px 15px 50px;
  box-shadow: 0 4px 20px rgba(0, 0, 0, 0.2);
  transform: rotate(-2deg);
}

/* Rounded photo frame */
.frame-rounded {
  border-radius: 16px;
  overflow: hidden;
  box-shadow: 0 8px 32px rgba(0, 0, 0, 0.12);
}

/* Glass morphism frame */
.frame-glass {
  background: rgba(255, 255, 255, 0.15);
  backdrop-filter: blur(12px);
  border: 1px solid rgba(255, 255, 255, 0.25);
  border-radius: 16px;
  padding: 16px;
}
```

#### Photoshop Frame Techniques
- **Stroke Effect**: Layer > Layer Style > Stroke. Position: Inside for clean edges. Use gradient strokes for metallic/gold look.
- **Inner Shadow**: Simulates depth — makes image look recessed into a mat/frame.
- **Pattern Overlay**: Apply ornamental patterns (damask, filigree) around image borders.
- **Custom Shapes**: Use rectangular frame shapes with ornamental corners. Apply layer styles for 3D embossed look.
- **Clipping Masks**: Place photo inside a decorative shape layer as clipping mask.
- **Vignette**: Lens Correction filter or manual radial gradient on mask to darken edges, creating a natural frame effect.

#### Creative Frame Ideas
- **Floating Frame**: Small gap between image and border (use inner padding with contrasting background).
- **Torn Paper Edge**: Use custom brushes or filters to create organic, torn paper borders.
- **Film Strip**: Create repeating perforated borders mimicking analog film.
- **Watercolor Edges**: Use watercolor brushes to mask/reveal edges for artistic look.
- **Geometric Frames**: Hexagonal, circular, or triangular frames using CSS `clip-path` or Photoshop vector masks.

## Procedure

### When asked to create/edit a visual design:

1. **Clarify Requirements**: Determine platform, dimensions, target audience, brand guidelines, and mood/style.
2. **Choose the Right Tool**: Photoshop for complex editing/compositing, Canva for quick marketing assets, CSS for web frames/borders.
3. **Start with Structure**: Grid, layout, hierarchy before details. Block out major elements.
4. **Apply Brand Elements**: Colors, fonts, logos, consistent with brand guidelines.
5. **Refine Details**: Adjust spacing, alignment, shadows, effects. Check at 100% zoom AND actual display size.
6. **Export Correctly**: Choose format based on output (web vs print vs social). Optimize file size.
7. **Review Checklist**: Spelling, alignment, brand consistency, resolution, color mode, accessibility.

### When asked about Photoshop techniques:

1. Identify the specific technique category (retouching, compositing, color, effects).
2. Provide step-by-step instructions with exact tool names, settings, and shortcuts.
3. Include non-destructive workflow tips (Smart Objects, Adjustment Layers, masks).
4. Suggest alternative approaches when available.

### When asked about web design:

1. Consider responsive requirements and target devices.
2. Follow mobile-first design principles.
3. Provide both design guidance AND CSS/HTML implementation.
4. Ensure accessibility compliance (WCAG 2.1 AA minimum).

### When asked about Canva:

1. Identify the design type and recommend optimal template dimensions.
2. Suggest templates and elements from Canva's library.
3. Guide through customization with brand elements.
4. Recommend Pro features when they add significant value.

### When asked about frames/borders:

1. Determine if the frame is for web (CSS), for image editing (Photoshop), or for quick design (Canva).
2. Provide code (CSS) or step-by-step instructions (Photoshop).
3. Consider the overall design aesthetic and brand.
4. Suggest multiple frame styles for comparison.

## App Landing Page Imagery (added 2026)

When designing landing pages for SaaS, apps, agencies and creator products in the **Sland / Bingle / Awwwards aesthetic** (soft pink-purple gradients, floating phone mockups, organic blobs, generous whitespace), you have two equally valid paths: **procedural SVG** (zero deps, infinitely scalable, instant load) or **AI-generated raster** (Midjourney/DALL·E/SD).

### Reference style summary
- Palette: magenta `#ec268d` → violet `#7b3ff2`, with peachy `#ff8ed1` accents on near-white `#fafafa` backgrounds. Dark sections use deep navy `#0f1230` to `#1f2147`.
- Composition: hero phone tilted slightly, floating mini cards near phone (metric chips, avatars, ratings), 2-3 organic blobs blurred behind, kinetic typography with split-text reveals.
- Mood: optimistic, premium, friendly. Generous whitespace. No stock photos that look like stock photos.

### Procedural SVG techniques (used in pixelcodestudio project)

These patterns avoid external assets entirely and ship sub-10kB:

1. **Phone frame** — viewBox `0 0 400 600`, rounded outer rect (rx=44), inner screen rect (rx=32), notch as small rounded rect at top, optional reflection via white linear-gradient at 8% opacity.
2. **Organic blob** — single closed path with 4-6 cubic Bézier control points, fill = `<radialGradient>` with two color stops, `filter: blur(40px)` via CSS, `opacity: 0.5`. Animate `transform` rotate + scale on a 12-20s `ease-in-out` infinite alternate.
3. **Procedural avatar** — gradient circle background + initials in display font (Sora/Plus Jakarta) + subtle shoulder arc (`<path d="M40 200 Q40 130 100 130 Q160 130 160 200 Z">`).
4. **Card cover (blog/portfolio/template)** — gradient `<rect>` + 1-2 large soft circles at low opacity for "depth" + 2-3 thin rounded rects as fake content placeholders.
5. **Connected node diagram** — central logo node + 5-6 satellite circles with brand symbols, connected by `<path stroke-dasharray="2 6">` and animated `stroke-dashoffset`.
6. **Counter UI chips** — pill-shaped rounded rects with icon + bold number; place absolutely near phone with `translate-y` float animation.

### Hand-off checklist for AI-generated images

1. Generate at 2x intended display size (Retina).
2. Run through `squoosh.app` → WebP @ 80% quality + AVIF fallback.
3. Add `loading="lazy"` and explicit `width`/`height` to prevent CLS.
4. For people: verify license allows commercial use. Prefer prompts that produce diverse subjects (vary skin tone, age, gender, ability).
5. Replace any rendered text inside the image — AI text is usually broken. Composite real HTML/CSS text on top.
6. Match brand palette: pull dominant color via Coolors, nudge with Photoshop Selective Color or CSS `hue-rotate` if needed.
