# Tamanhos de Banners — Referência Oficial

Fonte: Google Ads Help, Meta Business Help Center, documentação oficial das plataformas.

## Google Ads (Display Network)

### Desktop

| Tamanho | Nome | Uso Recomendado |
|---------|------|-----------------|
| 300×250 | Medium Rectangle | **Mais popular** — inline em artigos, sidebar |
| 336×280 | Large Rectangle | Inline em conteúdo, alta performance |
| 728×90 | Leaderboard | Topo de página, header |
| 970×90 | Large Leaderboard | Topo de página, alta visibilidade |
| 468×60 | Banner | Topo/rodapé, banner clássico |
| 300×600 | Half Page | Sidebar, alto impacto, muito espaço |
| 160×600 | Wide Skyscraper | Sidebar lateral |
| 250×250 | Square | Sidebar, espaços pequenos |
| 200×200 | Small Square | Espaços compactos |

### Mobile

| Tamanho | Nome | Uso Recomendado |
|---------|------|-----------------|
| 300×250 | Medium Rectangle | Inline em conteúdo mobile |
| 300×200 | Mobile Banner (large) | Feed mobile |
| 300×50 | Mobile Banner | Header/footer mobile |
| 300×100 | Large Mobile Banner | Header mobile, boa visibilidade |
| 250×250 | Square | Feed, inline |
| 200×200 | Small Square | Espaços compactos |

### Responsive Display Ads (Recomendado pelo Google)
- O Google recomenda Responsive Display Ads que ajustam automaticamente
- Envie assets: headline, description, logo, imagem 1200×628 (landscape) e 1200×1200 (square)

## E-mail Marketing

| Tamanho | Formato | Uso |
|---------|---------|-----|
| 600×200 | Header | Cabeçalho do e-mail |
| 600×300 | Hero | Imagem principal |
| 600 max width | Layout | Largura máxima recomendada |
| 560 content | Conteúdo | Com 20px padding lateral |

**Nota**: E-mail tem limitações severas — usar `<table>` layout, inline CSS, imagens com alt text.
